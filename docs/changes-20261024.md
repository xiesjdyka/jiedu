# 未发布更新汇总 · 2026-10-24

这批变更汇总 1.1.8 之后已在本机应用的维护代码。当前为待推送源码，版本号暂保留 1.1.8；不代表已发布新安装器或更新通道。正式发布前须另行确定版本、重建安装包并验收。

## 客户端接入与归档

- 接入入口统一显示客户端和连接状态；复制接入提示词、已发指令、真实读取验证分别记录。用户点击“已发指令”不等于客户端已经连接。
- 增加 DSH、Claude、Cursor、WorkBuddy、OpenCode、ZCode 的本机来源适配。Claude Desktop 使用本机 MCP 扩展包连接知识工具，归档能力受本机可读缓存限制。
- 排除结构上可识别的思考、工具调用与工具返回；进度说明可留在对话原文，不能作为正式知识事实直接提炼。保留用户正文和已完成答复，并按来源身份处理历史补档、续读及重复记录。
- 附件按已发送消息的真实引用关联，能取得的原件保留；无法取得时如实记录缺失，不以同名文件替代。各客户端附件格式的覆盖程度仍以实际来源与验证结果为准。
- 本机安装状态、连接验证与归档状态统一解释。软件被移除时保留原档案及设置，回到待接入状态；缺少可靠安装证据时不把历史读取成功当作当前在线。
- 已接入客户端优先显示；高级状态和技术细节收拢。隐藏客户端是工作区内的用户设置，源码不携带任何人的隐藏选择。
- 推送准备时补充修复已配对连接删除：只清理匹配自身身份的配置，保留其他配置及并发产生的继任连接。此项为待发布源码修复，未追加部署到既有本机程序。

## 管家与检索

- 补充产品能力、实际状态和工具说明，完善 Hermes 工具桥接及本机接入指令。
- 外部模型仍受工具权限和知识写入确认约束；用户授权前不自动写入正式知识。
- 向量编码服务按需启动，空闲 10 分钟后退出释放资源；加载中和失败状态如实报告，关键词检索可作为降级路径。

## 整理稳定性

- 新建议只有在当前授权下完整读取固定证据窗口后，才由服务端标记为可容忍后续追加。
- 对话仅追加新内容时，已读取且未变化的窗口继续有效；新增尾部交给下一次增量整理。建议卡与保存页明确显示这一覆盖范围。
- 改写或截断旧内容、来源身份变化、证据快照缺失或损坏、权限变化、目标知识页变化，仍需重新核对。
- 中断后的同请求重试仍复核证据与目标，不能提前把旧建议标成完成；固定批次保留进度，避免重试不断扩展任务边界。
- 旧建议不自动改成新协议已通过；需要实际重读后提交新建议。正式知识继续由用户确认。
- 本次继续采用一个 Codex 整理执行者，不引入多智能体分层整理流程。

## 验证与发布边界

追加稳定修复的冻结程序通过 95 项相关回归；独立审查另覆盖 11 项快照完整性、追加、身份权限、目标确认、批次边界场景。本机更新核对了程序文件及资料、配置、同步和整理记录保全。

这些结论仅覆盖对应源码和测试环境，不等同于所有客户端版本、全新 Windows 安装或新安装器的验收。待推送目录另做源码导出、依赖完整性、隐私检查和代表性回归；结果记录在准备清单中。原始聊天、个人知识、账户配置、密钥、机器路径、模型和运行时不属于源码提交。
