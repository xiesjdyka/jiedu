# 1.2.7 更新说明

界渡在软件更新前暂停接收新任务，等待已经开始的操作结束。独立 MCP、向量编码器和界渡服务完成当前工作后协作退出。维护期间 MCP 自动重连会收到稍后重试提示。若等待超时，软件更新页会显示仍占用安装目录的进程和 PID。

**首次从 1.2.6 升级**仍由 1.2.6 的更新助手执行。如果旧 MCP 连接持续占用安装目录，请先关闭该界渡连接，再回到「软件更新」重试。新的维护机制在成功安装 1.2.7 后生效。

Windows 隔离测试覆盖 MCP 的并发响应、取消、断线重连、HTTP 排空、编码器和更新助手。实际 Claude 或 Codex 客户端界面未参与这轮验证。

本版通过程序更新包交付。新用户可先安装 [1.2.3 完整安装包](https://github.com/xiesjdyka/jiedu/releases/download/1.2.3/Jiedu-1.2.3-windows-x64-setup.exe)，再在界渡内检查更新。
