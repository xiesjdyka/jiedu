# 1.2.1 更新说明

本批更新统一使用 **1.2.1** 编号，沿用已发布 1.1.10 的功能。本次仅调整版本编号及对应发布材料，没有新增采集或整理规则。后续维护版本依次使用 1.2.2、1.2.3。

这批功能重点是普通用户的操作流程：连接 AI、查聊天、整理知识各有清楚入口，减少重复页面和开发术语。

## 界面调整

- 聊天页聚焦已保存的会话和附件，整理工具与详细诊断移出日常查看流程。
- 整理页集中展示交给 Codex 的操作指引与待用户确认的结果。仅复制指令不会自动启动任务。
- 详细归档诊断集中到故障排查，普通页面使用简明状态和下一步提示。
- 全部历史完成后才能使用的总结功能保持原有核验要求；它不阻止对已保存资料进行普通整理。

## 保持原有数据与权限规则

本次界面调整不迁移或重置聊天档案、同步游标、身份权限和整理记录。正式知识仍由用户核对确认，客户端只有完成真实读取验证才算接入成功。

1.1.9 已有的客户端适配、历史补档、去重、附件关联及增量整理继续沿用。累计更新的通俗介绍见 [更新介绍与视频口播](whats-new-1.2.1.md)。

安装包及发布状态以 [GitHub Release](https://github.com/xiesjdyka/jiedu/releases/tag/1.2.1) 为准。
