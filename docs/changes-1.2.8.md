# 1.2.8 更新说明

界渡 1.2.8 换上全新界面，并修复会话刷新页的读取错误和几处偶发问题。你的知识库、聊天记录和设置不受影响。

**新界面**

- 新的开场画面和首页。首页用两个圆盘分别展示知识动态和已连接的外部 AI；首页显示几个 AI、具体显示哪几个，可以在「设置」里选择，也能一键恢复自动排序。
- 首页、「连接 AI」、「故障排查」和右上角运行状态读取同一份连接与服务状态，不再各说各的。「正常 / 需处理 / 中断 / 未接入」四种状态的颜色全站统一，浅色和深色主题各有一套。
- 重做「故障排查」页，集中显示本机服务、各 AI 的连接与读取情况，可以按状态筛选。
- 「设置」和「工作区」改为居中单列。读取数据时在原位置显示灰色占位条，不再在右下角弹出「正在更新」提示。
- 移除没有入口的旧页面（桥接状态、知识关系图）和随之不再需要的图表库（约 1 MB）。
- 新的蓝紫色标签页图标。

**修复**

- 「会话刷新」页在还没有勾选核心背景文件时打开会报错。现在会提示「尚未配置核心背景」，并引导你到「工作区」勾选文件；核心背景文件缺失、无法读取、不是 UTF-8 或为空时，也会分别说明原因。
- 会话列表在读取期间有会话被移除时，偶尔读取失败。
- 「整理知识」里的原始档案列表第一次打开时是空的，需要手动扫描。现在首次打开会自动扫描一次，并说明这里只列手动放入的 Markdown 文件，界渡自动采集的聊天在「聊天记录」里查看。
- 窄窗口下，会话刷新页的状态标签会断成两行。
- 运行状态检查现在报告服务实际使用的端口。

**验证范围**

界面在隔离的预览副本中逐页点击核对；后端修复在独立调试服务和调试数据上核对接口与页面，并通过相关单元测试。尚未用真实聊天记录完整走一遍「整理知识」流程，也未在 Claude 或 Codex 客户端界面中验证。

本版通过程序更新包交付。从 1.2.7 升级时使用 1.2.7 的更新维护机制；从 1.2.6 直接升级仍由 1.2.6 的更新助手执行，如果旧 MCP 连接持续占用安装目录，请先关闭该连接再回到「软件更新」重试。新用户可先安装 [1.2.3 完整安装包](https://github.com/xiesjdyka/jiedu/releases/download/1.2.3/Jiedu-1.2.3-windows-x64-setup.exe)，再在界渡内检查更新。下载文件与签名清单见 [1.2.8 发布页](https://github.com/xiesjdyka/jiedu/releases/tag/1.2.8)。
