# 界渡 1.2.9 更新说明

- 聊天记录改为全宽文档流。左栏保留标题、来源、时间和消息数，文件统计移到详情顶部。长路径和代码自动换行，自动任务标签默认折叠，点击可展开。
- 「故障排查」与「连接 AI」统一判断：配置有效的客户端不再误报未接入，本机未配置的客户端也不再误报需重连。
- 首页、设置及连接检查页面在轮询结果没有实质变化时保留现有内容，检查按钮切换文字时保持宽度，避免阅读中页面跳动。
- Windows 桌面窗口启动时自动最大化；原生标题栏随界面浅色或深色切换，窗口、托盘与快捷方式使用新版蓝紫图标。

本次更新含原生桌面外壳，需要使用完整 Windows 安装器。

此前通过程序更新升级的机器，如果出现“安装程序或运行环境文件已变化，请使用完整安装器修复”，请从本次 GitHub Release 下载完整安装器，保存当前工作，退出界渡并停止后台，再运行安装器。保留原工作区、原始聊天及配置，不要为消除此提示删除旧资料。
