# 界渡更新介绍：从 1.1.2 到 1.2.1

本批更新统一使用 1.2.1 编号，功能沿用 1.1.10。下文汇总的是从 1.1.2 至今的变化，不代表这些功能都在本次编号调整中新增。

## 一句话介绍

连接更多 AI，自动保存支持的聊天记录，再交给 Codex 整理成你能长期使用的知识。

## 这次有哪些值得说的变化？

### 1. 更多 AI 可以接入了

除了原有的 Codex、Hermes，增加 DSH、Claude、Cursor、WorkBuddy、OpenCode、ZCode 的接入和本机聊天记录适配。

不同 AI 可以按你的权限使用同一份知识库。其他支持 MCP 的客户端也能连接知识工具；自动保存聊天则需要对应的采集适配。

### 2. 接入从复制一段提示词开始

在界渡里选择对应的 AI，复制接入提示词，发给它，按照提示完成连接即可。需要你在客户端确认的步骤，会在接入指引中说明。界渡会在 AI 真正读取成功后显示连接结果。

Claude Desktop 当前使用连接扩展包：在界渡生成，再到 Claude 里安装启用。这是给现有 Claude 添加界渡工具，不是重新安装 Claude。

### 3. 聊天自动留下来，历史记录也能补

接入并启用后，界渡会补齐本机能够找到、能够读取的历史聊天，再持续保存新消息。中断后可以接着来，并识别重复记录。

支持的图片和附件会与对应消息一起保存；取不到原件时会说明缺失，不会拿同名文件冒充。

### 4. 少收过程噪声，留下有用内容

保留用户消息和已完成的回答，排除记录中能够识别出的思考、工具调用和工具返回。进度说明可以留在聊天原文里，整理时不直接当作正式知识事实。

### 5. 聊了新内容，不用轻易把旧内容再整理一遍

符合条件的整理建议会记住这次已经读取的范围。旧内容没变，整理结果继续有效；新增内容留给下一轮处理。真正改动了旧内容、知识页或权限时，仍会重新核对。

整理继续可以交给 Codex，正式知识由你确认后保存。

### 6. 常用界面重新分工

- **聊天记录**：找以前聊过的话和附件。
- **整理知识**：把整理指令交给 Codex，再查看、确认整理结果。
- **连接 AI**：接入客户端，查看连接和权限。

日常页面减少重复入口和开发术语。详细诊断放到故障排查中；历史记录还没全部补齐时，已经保存的内容仍可走普通整理流程。

### 7. 搜索按需启动，升级保留已有积累

按意思搜索所需的向量服务在使用时启动，空闲 10 分钟后释放资源；加载期间仍可用关键词检索。

升级会核验安装位置，保留资料、权限和同步进度；遇到无法确认归属的安装，不会直接覆盖。

## 一分钟视频口播

界渡更新了。这次最明显的变化，是除了 Codex 和 Hermes，还增加了 DSH、Claude、Cursor、WorkBuddy、OpenCode 和 ZCode 的接入适配。

大多数客户端，从界渡复制一段提示词发给它，就能按指引完成接入，让它使用你的知识库。支持的本机聊天记录会自动保存，历史记录逐步补齐，新消息继续跟上。

我们也减少了整理里的重复劳动。已经读完、没有变化的内容，不会因为你又聊了几句，就轻易要求全部重新整理。新增内容下一轮接着处理，最后由你确认哪些内容保存为正式知识。

界面也重新做了分工：想找以前的对话，就去聊天记录；想把内容整理好，就去整理知识；想接入新的 AI，就去连接 AI。尽量让大家打开之后，就知道下一步做什么。

## 录屏顺序

1. 展示客户端列表和新增适配。
2. 展示复制接入提示词和连接成功后的界面。
3. 在聊天记录里打开一段演示对话及图片。
4. 展示交给 Codex 整理的入口。
5. 展示整理结果的来源、修改内容，以及由用户确认保存。

录屏建议使用演示工作区和虚构聊天，不展示自己的密钥、私人对话或账户信息。

## 发布时保留的一句说明

聊天归档范围取决于客户端版本和本机可读记录。Claude 本地缓存不代表全部云端历史，图片和附件以实际取得的原件为准。
