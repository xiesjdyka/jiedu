# 1.2.3 更新说明

1.2.3 修复部分 Windows 环境中安装文件完整、关于窗口可以打开，但正常桌面启动被错误拒绝的问题。本版提供完整 Windows 安装器，新用户可以直接安装，无需先安装 1.2.1 再更新。

- 修正独立启动的判断：进程属于某个 Windows Job，不等于它仍受启动窗口的生命周期控制，避免将已经独立创建的后台服务误判为附属进程。
- 保留独立创建及服务就绪检查，增加出生时间、可执行文件和完整启动参数核验。创建被拒绝、身份不符或进程提前退出时，明确报告失败，不按返回的 PID 直接接管进程。
- 启动失败时只回收本次启动身份对应的进程，保留对无关进程和历史 PID 的保护。

本次修复不更改系统安全设置，不注册新的服务或计划任务。资料、权限、聊天归档和同步进度继续沿用原有保全规则。

本地回归使用合成工作区、真实 Windows 进程和可控 Job，覆盖宿主正常退出、被终止、独立 Job 成员、启动失败清理及身份不符；这些等价条件测试不表示已经取得或完整还原反馈者的电脑环境。完整安装器及桌面可用性的最终验收，以实际发布记录为准。

实际下载、签名清单与发布状态以 [GitHub Release](https://github.com/xiesjdyka/jiedu/releases/tag/1.2.3) 为准，本文本身不表示已经发布。
