# 1.2.2 更新说明

1.2.2 修复管家输出容量、Claude 本地聊天采集和客户端状态显示。

- 管家移除产品自设的每轮输出长度选项，按已核实的模型容量和剩余上下文请求；未知服务的输出长度由服务决定。
- Claude 本地采集按当前有效的 IndexedDB 外部对象元数据读取正文，单条记录异常不会阻断后续消息；缺失和未知结构保留待核对状态，避免把思考、工具内容或未完成回答当成最终回答。
- 连接 AI 页面区分当前配置、近期读取与历史读取。安装、配置、权限及记录变化在页面可见时统一刷新，保留编辑草稿并展示刷新失败与重试入口。

本版通过 `.jiedu` 程序包交付，原生外壳构建版本保持 1.2.1，Python、向量及 OCR 运行资源保持不变。已有 1.2.1 用户可在界渡中检查更新；新用户先安装 1.2.1，再检查更新至 1.2.2。原资料、权限与同步进度沿用原有保全规则。

可公开回归全部使用合成数据。实际发布状态与文件以 [GitHub Release](https://github.com/xiesjdyka/jiedu/releases/tag/1.2.2) 为准。
