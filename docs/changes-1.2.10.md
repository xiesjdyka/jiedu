# 界渡 1.2.10 更新说明

- 在「连接 AI → 聊天来源管理」中，可选择 Antigravity 的本机会话或全部可读会话归档，也可暂停。只读取本机当前分支可核实的用户与助手消息，无需 MCP 配对，不会写入正式知识。
- 保留消息正文中的代码；工具调用、思考、终端输出不作为对话消息。用户图片按可读本地原件关联。来源正在写入时等候重试，原会话归档保留；不承诺恢复已删除会话或非活动分支历史。

本次为程序更新，沿用 1.2.9 桌面外壳，不替换 EXE。若从更早版本跳过 1.2.9 更新，原外壳会保留；要使用新图标、启动最大化和主题标题栏，请先安装 [1.2.9 完整版](https://github.com/xiesjdyka/jiedu/releases/download/1.2.9/Jiedu-1.2.9-windows-x64-setup.exe)，然后更新程序。
