# 权限与客户端身份

## 推荐接入方式

在“AI 连接”中登记客户端并完成配对，再按需要授权资料范围与操作。客户端名称和 `client_id` 是标识，不是密码。安装连接、选择模型或声明名称均不等于取得读取授权。

stdio MCP 使用 `KNOWLEDGE_BRIDGE_CLIENT_ID` 与 `KNOWLEDGE_BRIDGE_CLIENT_SECRET`；请由本机配置提供真实凭据，不写进公开示例、源码或截图。HTTP 示例的 `JIEDU_CLIENT_ID` / `JIEDU_CLIENT_SECRET` 是示例客户端使用的环境变量，不能与 stdio 的名称混用。参见 [项目接入入口](../README.md)。

## 服务端判定与兼容路径

已认证客户端按实际工具要求的资料范围、操作和选择对象，由服务端权限服务判定；需要审批的操作须完成相应批准。无效、撤销或受限的凭据不能通过换一个工具参数冒充别的客户端。

当前仍保留部分旧正式知识工具的兼容路径：未使用新身份认证时，这些工具依旧检查旧记忆接口开关、客户端和工具权限。这不是“所有工具都强制新凭据”的统一模式，不应按后者宣传。原始证据、通用授权对象读取等新工具另有认证要求；不能凭旧正式知识工具可调用，推定能够读取全部资料。具体以当前工具和服务端结果为准。

## 读写边界

- 读取：仅在获准范围内搜索和读取，返回的片段不是整库已读证明。
- 原始归档：按权限追加用户和助手的可见原文及明确附件引用，不任意改写原历史。
- 正式知识：AI 提交候选或变更请求，经过来源、版本、差异与用户确认后写入；备份和撤销受相应流程约束。
- 本机文件授权与网络外发不是同一个授权。启用外部模型或搜索时，请查看将发送的资料范围。

## 部署与审计

Console 默认使用本机回环地址，stdio MCP 是本地进程通路。本轮不把公网部署、企业隔离或任意远程访问列为已验收能力。原始资料、索引、运行配置、凭据和审计属于用户工作区与运行状态，不属于公开源码包。

服务端保留相应工具调用与拒绝记录。排查时结合具体操作、客户端身份和工作区状态；不要向公开问题贴出完整凭据、私人路径、原文或审计内容。工具返回的知识是资料，不是可信系统指令。
