# 1.1.2 发布审阅版与验收边界

本候选尚未公开发布。新候选安装包的安装、升级及运行验收，以对应 SHA256 的随附回执为准。公开源码仅按 `public-source-files.txt` 导出，不公开私人资料、配置、凭据或内部回执目录。

`docs/validation.json` 原样保留 2026-10-15 的 rc1 源码预览记录；其中日期、候选与限制均属历史范围，不是本轮 1.1.2 安装包验收。

## 本候选新增

- 统一中性暗底与克制青绿强调；输入区和设置控件展示明确的开、关及不可用状态，保留键盘操作与可见焦点。
- 更新流程新增启动与常驻后台检查、稍后提醒、一次开始安装、忙时等待与失败恢复；新原生壳和安装快捷方式统一 v1 图标。完整安装版与自包含工作区的升级边界分别核对。

- 桌面聊天布局、模型菜单与设置交互，保留界渡品牌和返回工作区入口；新对话创建期间保留快速输入。
- 可切换思考的模型在没有保存偏好时默认开启，已有明确关闭选择保留；不支持或未验证的能力保持关闭，必须思考的模型按其能力执行。
- 外部模式的自动生成目标为思考开启 8192 词元、关闭 4096 词元，受服务输出上限和实际上下文夹紧；思考与回答共用额度，明确选择的数字和“最大”不被自动覆盖。
- 具备图片能力的外部模型可接收原图，支持选择、拖拽、粘贴、预览、移除和图片单独提问。应用限额为单张 8 MiB、每轮 4 张合计 16 MiB；不自动 OCR 或写入知识。本机模型和 Hermes 通路不自动改用文字代替图片。
- 每会话未发送图片草稿同为 4 张/16 MiB，可刷新恢复；24 小时规则只清理未绑定原件。已发送原件受保护，状态不明的原件保留并计入容量，不自动发送。
- 同一对话、同一外部接入配置下最多使用 8 对已完成问答及其可核验图片，超过容量整对省略较早内容并提示。旧本地、其他配置、工作区或工具派生历史、全库和画像不自动外发；旧图缺失或变化时提示重新选择。

## 版本与安装边界

程序、安装器、Python 包、Cargo、Tauri 与重新编译的原生外壳文本版本统一为 `1.1.2`，Windows 数字文件版本为 `1.1.2.0`。窗口、托盘和安装快捷方式使用定稿 v1 图标。完整版本核验详见[统一发布版本](release-version.md)。

本候选是联网安装器，自动下载并校验 Python 3.13.16、固定 BAAI/bge-m3 向量模型及 OCR 运行环境和模型。安装完成后两项能力可离线使用；管家生成模型不附带。程序、资源、解释器、安装升级与卸载保全的实际结果以安装器 SHA256 对应回执为准。

## 已有证据与历史记录

源码的隔离合成回归覆盖自动额度及上限约束、图片与草稿生命周期、同配置有限历史和外发边界。隔离聊天预览已有原图上传、预览、思考、流式回答、刷新草稿与旧图续聊、自动选择保存等证据；这些是源码或预览证据，不能替代新安装器的独立验收。

旧 rc4 及此前版本曾在现有 Windows 的独立目录验证完整安装、未初始化启动、工作区绑定、WebView、关窗收进托盘、重复启动复用后台、覆盖安装，以及卸载保留合成资料和同步游标。签名更新也有测试通道的真实应用、重启与资料保全记录。这些均为历史验收，不宣称本轮已在新 Windows 系统或所有 Windows 版本通过。

本机 Hermes 问答沿用独立入口，可复用其已有模型配置，发送本轮问题、公开产品说明和当前界渡对话的有限已完成问答。此前 DeepSeek 的连续问答、重启续接、取消与恢复有合成内容实测；不加载旧 Hermes 会话，不执行界渡工具或私有知识检索，其他供应商和任意 Hermes 版本不作兼容承诺。Hermes 问答、来源归档和 MCP 连接分别管理。

## 原档案与知识边界

来源归档应保留用户可见发言、commentary 进度和正文中的代码例，保存它们不等于写入正式知识。整理依据来源提炼可核实事实、已作决定及必要约束，保留出处并经预览核对。内部 analysis、工具原始结果、用量和协议记录不应混作普通聊天；应按来源结构识别，不能按正文关键词删除真实内容。各来源适配的实际过滤与恢复结果，以该候选的测试和回执为准；日志数量不等于聊天数量，失效附件不保证找回。

本轮结构检查覆盖已核对的 Codex/Hermes 消息适配、逐消息整理的入口/复核/交付，以及精确 archive_message 证据资格。原始证据展示仍可单独保留提示和工具记录；通用整份 conversation.md 读取与 Wiki 尚未逐消息投影，不声称所有入口均已覆盖。不重置来源游标，也不改写已有历史或账本。

## 更新与公开发布边界

发布归属已确认为 `xiesjdyka/jiedu`，当前仓库仍为私有，尚未正式发布。应用已配置固定 HTTPS 更新清单地址；404、未发布和网络失败如实展示，不称为最新版。启动及托盘常驻时低频检查，发现新版本提供不抢焦点的提示、稍后提醒和手动检查。一次开始更新后下载、验签验摘要、等待任务自然结束，再交接安装和恢复使用。原生壳或 Python 变化使用同一入口的签名完整安装器；未配置或无法核验的安装归属安全拒绝。详见[更新协议和保全边界](update-release.md)。

人工审阅的 Windows 体验预览可不含 Authenticode 签名，并须如实提示未签名；这不替代或放宽程序更新的 Ed25519 校验。尚无 Windows 全版本覆盖、公开渠道联调、独立安全审计、完整离线安装、全部 OCR 类别准确率或任意 Hermes 版本兼容承诺。公开发布和服务部署仍须用户审阅。
