## 本候选新增

- 统一中性暗底与克制青绿强调；输入区和设置控件展示明确的开、关及不可用状态，保留键盘操作与可见焦点。
- 更新流程新增启动与常驻后台检查、稍后提醒、一次开始安装、忙时等待与失败恢复；新原生壳和安装快捷方式统一 v1 图标。完整安装版与自包含工作区的升级边界分别核对。

- 桌面聊天布局、模型菜单与设置交互，保留界渡品牌和返回工作区入口；新对话创建期间保留快速输入。
- 可切换思考的模型在没有保存偏好时默认开启，已有明确关闭选择保留；不支持或未验证的能力保持关闭，必须思考的模型按其能力执行。
- 外部模式的自动生成目标为思考开启 8192 词元、关闭 4096 词元，受服务输出上限和实际上下文夹紧；思考与回答共用额度，明确选择的数字和“最大”不被自动覆盖。
- 具备图片能力的外部模型可接收原图，支持选择、拖拽、粘贴、预览、移除和图片单独提问。应用限额为单张 8 MiB、每轮 4 张合计 16 MiB；不自动 OCR 或写入知识。本机模型和 Hermes 通路不自动改用文字代替图片。
- 每会话未发送图片草稿同为 4 张/16 MiB，可刷新恢复；24 小时规则只清理未绑定原件。已发送原件受保护，状态不明的原件保留并计入容量，不自动发送。
- 同一对话、同一外部接入配置下最多使用 8 对已完成问答及其可核验图片，超过容量整对省略较早内容并提示。旧本地、其他配置、工作区或工具派生历史、全库和画像不自动外发；旧图缺失或变化时提示重新选择。

## 版本与安装边界

程序、安装器、Python 包、Cargo、Tauri 与重新编译的原生外壳文本版本统一为 `1.1.3`，Windows 数字文件版本为 `1.1.3.0`。窗口、托盘和安装快捷方式使用定稿 v1 图标。完整版本核验详见[统一发布版本](release-version.md)。

本候选是联网安装器，自动下载并校验 Python 3.13.16、固定 BAAI/bge-m3 向量模型及 OCR 运行环境和模型。安装完成后两项能力可离线使用；管家生成模型不附带。程序、资源、解释器、安装升级与卸载保全的实际结果以安装器 SHA256 对应回执为准。

## 原档案与知识边界

来源归档应保留用户可见发言、commentary 进度和正文中的代码例，保存它们不等于写入正式知识。整理依据来源提炼可核实事实、已作决定及必要约束，保留出处并经预览核对。内部 analysis、工具原始结果、用量和协议记录不应混作普通聊天；应按来源结构识别，不能按正文关键词删除真实内容。各来源适配的实际过滤与恢复结果，以该候选的测试和回执为准；日志数量不等于聊天数量，失效附件不保证找回。

发布归属已确认为 `xiesjdyka/jiedu`；该历史候选阶段仓库仍为私有，尚未正式发布。应用已配置固定 HTTPS 更新清单地址；404、未发布和网络失败如实展示，不称为最新版。启动及托盘常驻时低频检查，发现新版本提供不抢焦点的提示、稍后提醒和手动检查。一次开始更新后下载、验签验摘要、等待任务自然结束，再交接安装和恢复使用。原生壳或 Python 变化使用同一入口的签名完整安装器；未配置或无法核验的安装归属安全拒绝。详见[更新协议和保全边界](update-release.md)。
